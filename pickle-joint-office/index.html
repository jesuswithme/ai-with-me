실시간 DB 연결
지금은 로컬 모드입니다. 이 브라우저(탭 여러 개 포함)에서만 데이터가 공유됩니다.

준비 5분:

  1. console.firebase.google.com → 프로젝트 만들기
  2. 빌드 → Realtime Database → 데이터베이스 만들기 (위치 아무 곳)
  3. 규칙(Rules)을 {".read":true,".write":true} 로 바꾸고 게시 ※ 링크를 아는 사람은 누구나 쓸 수 있으니 가족·팀 내부용으로만
  4. 데이터 탭 위의 URL(예: https://xxx-default-rtdb.firebaseio.com)을 위에 붙여 넣기

준비 5분 (구글 시트 DB 사용):

  1. 저장소의 apps-script/Code.gs 내용을 복사
  2. ‘피클 합동 비서실 DB’ 시트 → 확장 프로그램 → Apps Script → 붙여 넣고 저장
  3. 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: 모든 사용자 → 배포
  4. 나온 웹앱 URL을 위에 붙여 넣기 (5초마다 자동 동기화)

시트: 피클 합동 비서실 DB 열기

연결하면 지금 이 브라우저의 데이터가 DB로 올라가고, 이후 여러 기기에서 같은 오피스를 함께 씁니다.
